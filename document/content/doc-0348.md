## Executive Summary

오늘은 Promo Wizard의 4단계 흐름을 실제 생성 플로우에 더 가깝게 연결했다.

주요 성과는 다음과 같다.

### 3. Final Design이 LO-FI 레이아웃을 따르지 않는 이슈 분석

작성 문서:

- `docs/final-design-lofi-layout-fidelity-issue-2026-07-10.md`

확인된 핵심 원인:

- Step 4 UI 연결 문제라기보다 `final_design` worker 입력 계약이 부족하다.
- 현재 final worker payload에는 주로 다음 값만 전달된다.
  - `runId`
  - `runKey`
  - `stage`
  - `taskId`
  - `finalDesignId`
  - `confirmedDraftId`
- payload에 Confirm Draft의 실제 레이아웃 근거가 없다.
  - `draft_image_url` 없음
  - `draft_prompt` 없음
  - `draft_attempt` 없음
  - LO-FI layout fidelity policy 없음
  - reference image URL 없음
- 따라서 n8n final worker가 DB/API를 다시 조회하지 않는 한, 선택된 LO-FI의 레이아웃을 알 수 없다.

문서에 포함한 해결 방향:

- `promo-generation-final-designs.js`에서 confirmed draft row 조회 확장
- worker payload에 `confirmedDraft` 객체 추가
- `draftImageProxyUrl` 또는 absolute image URL 전달
- `layoutFidelityPolicy` 추가
- final worker에서 confirmed LO-FI 이미지를 reference image로 사용
- 필요 시 `final_design` 전용 prompt type 추가

## Important Findings

### Admin Page is DB-backed

관리자 페이지는 model/provider/responseFormat을 하드코딩해서 보여주는 구조가 아니다.

흐름:

```text
Admin Page
-> loadPromptTemplates()
-> GET /api/prompt-templates
-> prompt_templates DB table
-> selectPromptTemplate()
-> GET /api/prompt-template?id=...
-> promptEditor fields
```

따라서 Admin Page에서 값이 바뀌어 보이지 않는다면 원인은 다음 중 하나일 가능성이 높다.

- 운영 DB에 migration이 아직 적용되지 않았다.
- 기존 active `image_execution` row가 여전히 OpenAI/text 값이다.
- 브라우저에서 새로고침하지 않았거나 prompt list refresh가 안 됐다.
- 배포된 서버 코드가 아직 최신 commit을 반영하지 않았다.

### Local Codex Environment Has No DB Access

현재 로컬 Codex 작업환경에는 `DATABASE_URL`이 없다.

확인 결과:

```text
DATABASE_URL=missing
```

따라서 현재 세션에서 운영 DB에 직접 접속해 `prompt_templates` 값을 조회/수정할 수 없다.

가능한 방법:

- Admin Page에서 직접 수정
- Vercel/Neon 콘솔에서 migration 실행
- 임시로 `DATABASE_URL` 또는 `NEON_DATABASE_URL`을 작업환경에 제공
