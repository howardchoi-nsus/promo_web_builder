# Directus MCP 활용 방안

## 개요

Directus MCP는 AI가 Directus에 저장된 콘텐츠와 설정을 자연어로 조회하고 관리할 수 있도록 연결해 주는 기능이다.

운영자가 자연어로 요청하면 AI가 필요한 정보를 찾거나 새로운 콘텐츠 초안을 Directus에 저장할 수 있다. 다만 Directus MCP가 직접 디자인된 웹페이지를 만들거나 배포하는 것은 아니다.

## Directus MCP가 할 수 있는 일

Directus MCP는 Directus에 저장된 콘텐츠, 템플릿, 이미지, 번역과 설정을 검색할 수 있다. 새로운 콘텐츠를 등록하거나 기존 내용을 수정하고, 외부 이미지를 가져오거나 파일 정보를 정리하는 것도 가능하다.

또한 누락된 입력값이나 번역을 찾고, 이전 버전과 현재 버전의 차이를 요약하며, 검토 의견을 기록할 수 있다. 미리 허용된 Directus Flow를 실행해 검토나 페이지 생성 작업을 요청하는 것도 가능하다.

데이터 삭제, 구조 변경, 자동 승인과 공개도 기술적으로 연결할 수 있지만 운영 안전을 위해 사람의 승인을 받도록 제한해야 한다.

## 우리가 활용할 수 있는 기능

여기서 `우리`는 현재 구현된 **Promo Web Builder**를 의미한다. 페이지 생성·미리보기·편집 기능은 기존 웹빌더가 담당하고, MCP는 웹빌더가 사용할 설정과 콘텐츠를 준비하는 데 활용한다.

### 템플릿과 구성 요소 검색

현재 웹빌더에는 템플릿, 섹션 프리셋, 컴포넌트와 레이아웃 설정이 구현되어 있다. 이 데이터를 Directus로 이전하면 MCP로 조건에 맞는 템플릿과 섹션을 검색할 수 있다.

예를 들어 “한국 여름 이벤트에 사용할 Hero와 약관 섹션을 찾아줘”라고 요청할 수 있다. 실제 템플릿 추천과 페이지 조립은 기존 웹빌더가 수행한다.

### 프로모션 입력 Draft 작성

현재 웹빌더가 요구하는 제목, 설명, 기간, 대상 지역, CTA와 약관을 MCP로 작성할 수 있다. AI가 자연어 요청을 구조화해 Directus에 Draft로 저장하면 웹빌더가 해당 데이터를 불러와 생성 작업을 시작한다.

예를 들어 “8월 한국 사용자를 위한 여름 보너스 프로모션 초안을 만들어줘”라고 요청할 수 있다.

### 필수 콘텐츠 누락 확인

현재 섹션과 컴포넌트에 정의된 필수 입력값을 기준으로 제목, 이미지, CTA, 약관, 모바일 레이아웃과 번역이 빠진 항목을 찾을 수 있다. MCP는 누락 내용을 알려주거나 보완 Draft를 만들고, 최종 검증은 기존 웹빌더가 담당한다.

### 다국어 초안 작성

현재 Locale과 메시지 버전 데이터를 Directus로 옮기면 한국어 콘텐츠의 영어·일본어 번역 초안을 MCP로 만들 수 있다. 국가별 기간, 링크와 약관은 운영자가 확인한 후 웹빌더에 전달한다.

### 이미지와 디자인 자료 검색

웹빌더가 사용하는 PC·모바일 이미지와 디자인 자료를 Directus File Library에서 검색하고, 설명·태그·사용 지역을 정리할 수 있다. 새로운 이미지 생성, 섹션 배치와 품질검사는 기존 웹빌더 기능이 담당한다.

### AI Prompt와 Model 설정 확인

현재 관리자에 구현된 Prompt, Model과 Version 설정을 Directus로 옮기면 활성 설정 조회, Draft 복사, 버전 비교와 변경 내용 요약에 MCP를 사용할 수 있다. Prompt 검증, Model 호환성 검사와 최종 활성화는 기존 검증 로직과 사람의 승인을 거친다.

### 변경 내용과 사용 현황 확인

최근 변경된 템플릿, 사용되지 않는 컴포넌트, 번역 누락과 Draft 현황을 MCP로 검색하고 요약할 수 있다.

Promo Web Builder 기준으로 MCP를 우선 활용할 영역은 **템플릿·섹션 검색, 프로모션 입력 Draft, 누락 검사, 다국어 초안, 이미지 자료 검색, Prompt 설정 비교와 변경 현황 요약**이다.

## 별도 시스템이 필요한 기능

Directus MCP는 콘텐츠 관리 기능이므로 다음 작업은 별도의 실행 기능이 필요하다.

- 실제 웹페이지 화면과 레이아웃 생성
- GPT·Gemini 모델 호출
- AI 이미지 생성
- PC·모바일 디자인 품질검사
- 작업 상태, 실패와 재시도 관리
- 미리보기와 사용자 편집
- 최종 웹페이지 배포와 호스팅
- API Key와 Token 보관

MCP가 Directus Flow를 통해 이 작업을 시작하도록 만들 수는 있지만, 실제 처리는 연결된 웹페이지 제작 서비스나 AI 실행 서비스가 담당해야 한다.

## 권장 운영 방식

MCP에는 처음부터 모든 권한을 주지 않는다. 콘텐츠 조회와 Draft 작성부터 시작하고, 안정화된 이후 제한된 수정 권한을 추가한다.

Prompt와 Model 활성화, 콘텐츠 공개, 데이터 삭제, 사용자 권한 변경은 운영자가 Directus 화면에서 직접 확인하고 승인하도록 한다. API Key와 Token은 Directus 콘텐츠에 저장하지 않고 별도의 Secret 저장소에서 관리한다.

## 최종 정리

Directus MCP는 자연어로 콘텐츠와 설정을 찾고 작성하는 관리 도우미다. 우리는 이를 프로모션 Draft 작성, 번역, 검색, 누락 검사와 검토 지원에 활용할 수 있다.

실제 웹페이지 생성과 AI 실행은 MCP가 담당하지 않는다. 따라서 Directus MCP는 제작 서비스를 대체하는 것이 아니라, 제작에 필요한 콘텐츠와 설정을 빠르고 정확하게 준비하는 역할로 사용하는 것이 적합하다.
