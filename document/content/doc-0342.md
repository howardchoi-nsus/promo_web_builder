# Handoff - 2026-07-03

## 오늘 진행 요약

오늘은 B섹션 프로모션 빌더의 기본 방향을 `템플릿 고정 입력`에서 `디자인 모드 기반 생성 흐름`으로 재정리했다. 핵심은 B1 기본설정을 다시 설계하고, 마켓/지역과 비주얼 생성의 역할을 분리한 것이다.

현재 기준 B1은 다음 구조로 확정했다.

```text
B1. 디자인 모드 선택

[라디오] AI 모드
[라디오] 고급 모드

마켓 / 지역 [공용 select]

고급 모드일 때만:
템플릿 선택 [Default Temp]
```

`비주얼 사용` 전역 옵션은 B1에서 제거했다. 앞으로 비주얼 생성 여부는 B3 섹션 초안에서 섹션/섹션아이템 단위로 제어하는 방향이다.

## 오늘 반영한 주요 내용

### 1. B1 디자인 모드 선택 구조 반영

파일:

- `prototype/index.html`
- `prototype/app.js`

반영 내용:

- `B1. 템플릿 및 모드`를 `B1. 디자인 모드 선택`으로 변경
- `AI 모드 / 고급 모드` radio 선택 추가
- 기본값은 AI 모드
- 고급 모드 선택 시에만 `템플릿 선택` 출력
- POC 템플릿은 `Default Temp` 하나만 제공
- 내부 값은 `default_temp`
- `템플릿 선택` 옆에 `POC에서는 default_temp만 사용할 수 있습니다.` 문구 배치

payload 반영:

```json
{
  "designMode": "ai",
  "selectionMode": "auto",
  "promoTemplate": "AI Auto"
}
```

```json
{
  "designMode": "advanced",
  "selectionMode": "manual",
  "selectedTemplateId": "default_temp",
  "promoTemplate": "default_temp"
}
```

- `마켓 / 지역`은 AI 모드와 고급 모드 모두에서 사용하는 공용 항목
- 텍스트 생성보다는 이미지 생성 방향성에 더 큰 영향을 주는 값으로 정의
- visible UI copy로 마켓명을 억지로 넣지 않음
- 이미지 생성에서는 subtle visual localization context로 사용
- 국기, 지도, 고정관념적 문화 상징, annotation label로 쓰지 않도록 규칙 추가

```json
    "visualInfluence": "medium_high",

    "visualMood": "...",
    "avoid": []
  }
}
```

## 현재 남은 이슈 / 주의점

### 1. B3 섹션/섹션아이템 제어 미완

현재 B3에는 섹션 초안 편집 UI가 있지만, 요구한 최종 형태는 아직 아니다.

남은 항목:

- 섹션 출력 여부 on/off
- Header 상단 고정, Footer 하단 고정
- 그 외 섹션 drag reorder
- 섹션 아이템별 출력 여부
- 섹션 아이템별 이미지 생성 여부
- CTA Button은 해당 섹션 이동 시 함께 이동

### 2. n8n 운영 JSON 최종 동기화 필요

프롬프트와 앱 payload는 개선됐지만, 운영 n8n JSON에 오늘 변경된 `designMode`, `marketVisualGuidance`, 섹션/아이템 제어 정책이 완전히 반영됐는지는 별도 점검이 필요하다.

점검 필요:

- 운영 Code node에서 `marketVisualGuidance` 전달 여부
- image prompt 생성 노드에서 market을 visible label이 아닌 visual context로 처리하는지
- `Section Order`/section label guard가 계속 유지되는지
- AI 모드와 고급 모드 payload 차이를 n8n이 구분하는지

### 3. 배포 환경 확인 필요

로컬 서버에서는 변경 사항이 확인됐다. 배포 사이트에서 보이지 않는 경우는 배포 미반영 또는 캐시 문제일 가능성이 높다.

확인 필요:

- 실제 운영 URL에서 script version 반영 여부
- Vercel 배포 커밋/브랜치 확인
- 브라우저 캐시 무효화
