# 프로모션 빌더 Create Promo UX 검토

- 검토일: 2026-11-01
- 범위: 제작 방식 선택 → 와이어프레임 콘텐츠 편집 → 실시간 미리보기
- 환경: 로컬 fixture 서버, 데스크톱/모바일 반응형 브라우저

## 사용자 여정 상태

| 단계 | 변경 전 | 개선 후 |
| --- | --- | --- |
| 제작 방식 선택 | 모바일에서 세 번째 AI 모드가 첫 화면 아래로 밀림 | 카드 높이와 여백을 줄이고 데스크톱은 3열로 정리 |
| 와이어프레임 진입 | 전용 모드에도 `Layout & Design / Design` 전환 노출 | 전용 모드에서는 콘텐츠 구조 편집만 노출 |
| 모바일 편집 | 콘텐츠 트리와 미리보기가 길게 이어져 왕복이 어려움 | `콘텐츠 / 미리보기` 전환을 제공하고 선택한 패널만 노출 |
| 섹션 식별 | `SECTION 01 · 섹션 01`이 중복 표시됨 | 기본 이름일 때 `SECTION 01`만 표시, 사용자 지정 이름은 함께 표시 |
| 키보드 편집 | 미리보기 요소가 클릭만 지원 | Enter/Space로 항목을 선택하고 연결된 텍스트 입력으로 포커스 이동 |
| 헤더 상태 | 모드 선택 전부터 `Step 1 / 4` 표시 | 선택 화면은 `Create Promo`, 와이어프레임 진입 후 `Wireframe` 표시 |

## 반영한 개선

1. `?mode=wireframe` 요청은 저장된 Design 상태보다 우선하도록 고정했다.
2. 전용 와이어프레임 모드에서 레이아웃/디자인 전환 바를 제거했다.
3. 980px 이하에서 콘텐츠와 미리보기를 전환하는 모바일 컨트롤을 추가했다.
4. 모드 선택 카드를 모바일 첫 화면 안에서 모두 확인할 수 있도록 압축했다.
5. 기본 섹션명 중복을 제거하고 미리보기 항목에 키보드 접근성을 추가했다.
6. 변경된 CSS·JavaScript·부트스트랩에 캐시 버전을 갱신했다.
