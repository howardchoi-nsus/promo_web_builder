# AI 구성 자동 적용 및 템플릿 미리보기 후속 To-do

## 0. 문서 정보

- 작성일: 2026-07-28
- 대상: 프로모션 빌더 Step 2 `Template`
- 상태: P0 개발 및 로컬 검증 완료, P1·P2 후속 개발 대기
- 우선 방향:
  - AI 구성 결과가 정상이라면 템플릿 선택과 구성을 자동 적용하고 Step 3으로 이동한다.
  - 사용자가 템플릿 구조를 사전에 이해할 수 있는 드래프트 썸네일과 미리보기는 별도 후속 단계로 구현한다.
  - 미리보기는 AI가 별도 이미지를 생성하는 방식이 아니라 공통 렌더링 엔진을 사용한다.

---

## 1. 현재 문제

- 추천 템플릿 카드만으로 실제 섹션 구조와 컴포넌트 배치를 알기 어렵다.
- AI 구성 초안에는 이미 선택 템플릿, 섹션, 컴포넌트 버전과 콘텐츠 매핑이 포함되지만 사용자가 다시 적용 버튼을 눌러야 한다.
- `초안 생성 → 결과 확인 → 초안 적용 → Next` 과정이 중복으로 느껴질 수 있다.
- 템플릿 구조 미리보기가 없으므로 현재는 Step 3 Live Preview에 진입해야 실제 결과를 확인할 수 있다.

### 기능

- [x] `AI 구성 초안 생성` 버튼을 `AI로 구성하고 다음`으로 변경
- [x] 구성 요청 성공 시 `proposal.templateId`의 템플릿 자동 선택
- [x] 제안된 섹션 순서와 컴포넌트 버전 적용
- [x] 허용된 Overview 콘텐츠 매핑 적용
- [x] 현재 프로모션 세션에만 결과 저장
- [x] 정상 검증 완료 시 Step 3 `Layout & Design`으로 자동 이동
- [x] Step 3 진입 시 AI 구성 적용 완료 안내 표시
- [x] Step 2로 돌아가 다른 템플릿을 선택할 수 있는 경로 유지
- [x] 기존 수동 템플릿 선택 방식 유지

### 자동 이동 차단 조건

- [x] 필수 Overview 값 누락
- [x] Overview fingerprint 불일치
- [x] 템플릿 버전 또는 활성 상태 변경
- [x] 활성 섹션 불일치
- [ ] 컴포넌트 버전 적용 직전 재검증
- [ ] 고정 위치 섹션 적용 직전 재검증
- [x] 서버 검증을 통과한 콘텐츠 매핑만 적용
- [x] 잠금 컴포넌트 매핑 제외
- [x] 중요 경고 또는 사용자 확인이 필요한 결과

차단된 경우 Step 2에 머물며 원인과 재시도 방법을 표시한다.

### 안정성

- [x] 생성 버튼 중복 클릭 차단
- [x] 요청 ID와 Overview fingerprint 재검증
- [x] 적용 시 활성 템플릿 상세 재조회
- [ ] 적용 실패 시 기존 선택 템플릿과 사용자 입력 복구
- [x] UI에서 같은 결과의 중복 적용 방지
- [ ] 자동 적용·실패·사용자 취소 이벤트 기록

### 완료 조건

- 정상 AI 구성 결과는 추가 적용 버튼 없이 Step 3에서 확인할 수 있다.
- 오류나 경고가 있는 결과는 자동 적용되지 않는다.
- 관리자 템플릿 원본은 변경되지 않는다.
- 사용자가 Step 2로 돌아와 수동 선택할 수 있다.

## 3. P1 — 템플릿 구조형 드래프트 썸네일

### 표시 범위

- [ ] 템플릿 카드에 섹션 순서 표시
- [ ] Header/Footer 고정 위치 표현
- [ ] 섹션별 상대 높이 표현
- [ ] 텍스트·이미지·CTA 등 컴포넌트 유형을 플레이스홀더로 표현
- [ ] 추천 순위와 선택 상태를 썸네일과 함께 표시
- [ ] 썸네일 확대 또는 상세 보기 진입 제공

### 구현 원칙

- [ ] 공통 렌더러의 템플릿 스냅샷 계약 사용
- [ ] AI 이미지 생성으로 썸네일을 만들지 않음
- [ ] 사용자 프로모션 콘텐츠를 썸네일 생성에 사용하지 않음
- [ ] 관리자 기본 레이아웃과 활성 버전만 사용
- [ ] 템플릿 구조에 없는 임의 섹션이나 컴포넌트를 표시하지 않음

### 캐시 및 무효화

- [ ] 캐시 키에 template ID·version·layout revision·renderer version 포함
- [ ] 템플릿 활성 버전 변경 시 기존 썸네일 무효화
- [ ] 기본 레이아웃 변경 시 썸네일 재생성
- [ ] 컴포넌트 활성 버전 변경 시 영향 템플릿 썸네일 재생성
- [ ] 생성 실패 시 구조형 기본 플레이스홀더 표시

### 완료 조건

- 사용자가 템플릿 카드를 선택하기 전에 전체 섹션 구조를 식별할 수 있다.
- 썸네일 섹션 순서가 Step 3 Live Preview와 일치한다.
- 템플릿 목록 로딩 성능을 크게 저하시키지 않는다.

## 4. P2 — 실제 렌더링 템플릿 미리보기

### 기능

- [ ] 템플릿 카드 또는 상세 패널에서 실제 미리보기 열기
- [ ] 템플릿 기본 콘텐츠 적용
- [ ] 템플릿 기본 레이아웃 적용
- [ ] 활성 기본 디자인 토큰 적용
- [ ] 관리자 등록 기본 이미지 표시
- [ ] Desktop·Tablet·Mobile viewport 전환
- [ ] 미리보기에서 선택 후 Step 2로 복귀

### 렌더링 구조

- [ ] Step 3과 동일한 공통 렌더링 엔진 사용
- [ ] 편집 기능은 비활성화하고 읽기 전용으로 실행
- [ ] 템플릿 버전과 Layout revision을 미리보기 snapshot에 포함
- [ ] 이미지 자산은 서버 프록시 또는 현재 자산 접근 계약 사용
- [ ] 비공개 Blob의 직접 URL 노출 방지

### 완료 조건

- 미리보기와 Step 3의 섹션 구조·토큰·기본 콘텐츠가 동일하다.
- 이미지 자산 403 없이 표시된다.
- 읽기 전용 미리보기가 관리자 템플릿이나 사용자 세션을 변경하지 않는다.
