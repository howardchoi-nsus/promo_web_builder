## 3. 마지막 운영 데이터 확인 결과

Vercel Preview Protection Bypass를 적용한 Postman 요청으로 활성 템플릿 목록을 확인했다.

- Default Template: version `11`, 활성 기본 템플릿
- Promo_TempAAA: version `3`, 비기본 템플릿

첨부받은 Default Template 상세 응답을 검토한 결과, 현재 활성 version 11에는 `imageTarget: "item"`으로 설정된 섹션이 하나도 없었다. 따라서 Create Promo 오른쪽 CONTENT 패널에 Item용 `AI 이미지 생성` 버튼이 나타나지 않는 것은 현재 데이터 기준으로 정상 동작이다.

| 섹션 | 현재 AI 상태 | 이미지 대상 | Image Item | 판단 |
|---|---:|---|---|---|
| Header | 활성 | 섹션 배경 | Logo, Badges 등 | 텍스트/CTA가 없어 콘텐츠 분석 입력이 부족할 가능성이 높음 |
| Section A | 활성 | 섹션 배경 | 없음 | 배경 이미지 생성만 가능 |
| Section B | 비활성 | 섹션 배경 | Image | Item 생성 후보지만 AI 활성화와 대상 변경 필요 |
| Content CTA | 활성 | 섹션 배경 | `image` | 다음 Item AI 검증에 가장 적합 |

다음 검증에서는 `Content CTA`를 사용하는 것이 좋다. 텍스트, CTA 및 Image Item을 함께 갖고 있어 콘텐츠 기반 이미지 생성 조건을 충족하기 쉽다.

## 7. Postman 및 Preview Protection 메모

Preview Deployment가 Vercel Authentication으로 보호되어 있으면 일반 요청은 `401 Protected deployment`를 반환한다.

Postman 요청 시:

- Authorization 방식: `No Auth`
- Header: `x-vercel-protection-bypass: <Automation Bypass Secret>`
- 필요 시 Header: `x-vercel-set-bypass-cookie: true`

Automation Bypass Secret은 문서, 소스, 커밋, 채팅에 기록하지 않는다. Secret을 새로 만들거나 교체한 경우 새 Preview Deployment가 필요할 수 있다.
