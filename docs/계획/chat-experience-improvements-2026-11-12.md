# 채팅 경험 개선 계획

## 범위와 구현
1. 이전 CTA를 표시하고 클릭에 응답한다. 과거 요청은 재실행하지 않고 현재 결과 및 다음 가능한 행동을 안내한다. 현재 구성 승인만 기존 승인 흐름을 사용한다.
2. 상태 메시지에 여정 단계와 CSS mask reveal을 표시한다. 모션 감소 설정을 존중하고 표시 애니메이션은 생성·입력을 잠그지 않는다.
3. 상태 변화는 별도 메시지로 추가하고 기존 행은 보존한다. 같은 상태·문구의 반복은 추가하지 않는다. 메타데이터와 함께 기존 메시지 API에 저장한다. 관측된 실행 시간만 ETA에 사용하며 첫 실행은 계산 중으로 표시한다.
4. 일반 채팅 입력창을 내용에 맞춰 최대 180px까지 위로 확장하고 이후 내부 스크롤한다. 전송 시 축소하고 한글 조합 Enter는 전송하지 않는다.
5. 발송된 사용자 메시지의 텍스트를 오른쪽 정렬하며 문자 방향은 변경하지 않는다.
6. 사용자 말풍선은 내용 폭과 최대 폭을 사용한다. 긴 문장은 줄바꿈한다.

## 검증
- 순수 함수 회귀: 상태 추가·중복 억제·측정 ETA·과거 CTA 판별.
- Visual editor 빌드 및 기존 페이지 생성/승인 브라우저 회귀.
- 실제 LLM·운영 DB·Preview 연결은 별도로 검증하며 모의 테스트로 대체 완료 처리하지 않는다.
- 이번 요청은 개발 범위이며 Production 배포는 포함하지 않는다.

## 검증 결과
- Visual editor 빌드 통과.
- 채팅 경험 계약, 채팅 workspace 핸들러·계약 통과.
- PageSchema 여정 브라우저: 과거 CTA 무중복 실행, 진행 이력 추가, 입력창 확장, 한글 조합 보호, 말풍선 폭·정렬, reduced motion 확인.
- Hallmark 대화 여정 및 디자인 미리보기 이미지 재시도·자동 품질검사 브라우저 회귀 통과.
- ETA 관측치는 현재 앱 실행 중에 수집한다. 이력 행의 ETA는 저장되지만 사용자 세션 간 평균을 산출하는 운영 통계 기능은 포함하지 않는다.
- 실제 LLM·Neon·Blob 및 배포 환경은 미검증. Production 배포하지 않음.
