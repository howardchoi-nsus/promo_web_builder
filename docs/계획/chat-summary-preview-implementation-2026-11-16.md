# 채팅·요약·미리보기 개선 개발 결과

작성일: 2026-11-16 (Asia/Seoul)

## 반영

- 채팅 6개 항목은 `ea6b255` 구현을 재사용하고 기존 회귀를 실행했다.
- 상단 요청 요약을 구조화 데이터의 서술형으로 전환했다. 목적·대상·혜택·분위기와 실제 섹션 제목을 표시하며, 혜택 원문·순서를 보존한다. 상세 표는 유지한다.
- 기존 와이어프레임의 280자 생략과 배열 3항목 제한을 제거하고 문단 줄바꿈을 보존했다. 기존 URL·내부 키·미정 사실 필터는 유지했다.
- 고객 화면의 ‘기술 정보 보기’를 제거했다.
- PageSchema 생성 입력에 고정 섹션 목록을 강제하지 않는 동적 레이아웃 지침을 추가했다. 부모 내 박스 배치, 내부 글자 정렬, 형제 가로 나열을 구분하며 지원 스키마 외 CSS/HTML은 금지한다.
- 저장된 Revision의 `generationMeta.outputDiagnostics`에 후보 수, 노드별 선택 역할·토큰 연결, 이미지 요청·참조, 아이콘 등록 여부를 기록한다. 고객 화면에 추가 노출하지 않는다. 진단 값은 해당 저장 시점의 구조 정보이며 실시간 에셋 로딩 검사로 취급하지 않는다.
- 이미 존재하는 호환 토큰 후보 선별·타이포그래피 위계 지침·보더 조합 검증·미디어 준비·자동 보정은 재사용했다. 운영 토큰/활성 정책은 변경하지 않았다.
- 확정 표시 정책을 AGENTS.md에 반영했다.

## 검증

- Visual editor 빌드 통과.
- `qa:design-preview` 33개 계약·브라우저·PGlite 검사 통과. 서술형 요약, 기존 CTA·입력창·정렬, 동적 생성·승인·자연어 수정, 미디어 재시도, 자동 검사, SQL 저장 경로 포함.
- 와이어프레임 추가 회귀: 긴 문구 전체, 다섯 개 배열 항목, 빈 줄이 있는 문단 보존 통과.
- PageSchema API 추가 회귀: 동적 구조 지침이 실제 프롬프트 입력에 전달됨을 확인.
- 별도 `test-ai-builder-browser.mjs`는 분석 완료 대기에서 실패했다. 화면 진단은 `Cannot read properties of undefined (reading 'id')`이며, 해당 구형 fixture는 세션 POST만 구현하고 기존 클라이언트가 사용하는 세션 GET 복원 응답은 제공하지 않는다. 이 검사를 통과로 보고하지 않는다. 활성 핵심 여정은 별도 PageSchema/Hallmark 브라우저 검사로 통과했다.

## 운영 확인 및 잔여 검증

- 원격 main에는 채팅 개선 `ea6b255`와 품질검토 에이전트 `3097acb`가 아직 포함되지 않았다. 작업 브랜치 소스와 운영 배포를 구분해야 한다.
- 사이트 접속은 Cloud proxy CONNECT 403으로 차단되어 실제 운영 문서·배포 커밋·활성 프롬프트·토큰 후보를 확인하지 못했다.
- 실제 LLM·Neon·Blob·Vercel Preview 통합 검증 및 Production 배포는 미수행이다. 원격 main만으로 실제 운영 커밋을 확정하지 않는다.
- 동일한 레이아웃이 반복되는 실제 요청 사례는 운영 입력/AI 응답/저장 결과 비교가 필요하다. 이번 지침 보강으로 모든 실제 모델 요청이 원하는 구조를 생성한다고 보장하지 않는다.
- 운영 보더·이미지·폰트 문제의 원인이 설정 누락인지 AI 선택인지 실제 데이터로 확인해야 한다. 토큰이나 미디어를 임의 추가해 해결 완료로 처리하지 않았다.
- 품질검토 에이전트 배포 시 migration 092와 프롬프트 검증·활성화 상태를 별도로 확인해야 한다.
