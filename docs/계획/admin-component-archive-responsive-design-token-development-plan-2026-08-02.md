# 컴포넌트 보관 및 반응형 디자인 토큰 개선 개발 계획서

- 작성일: 2026-08-02
- 대상: 설정 > 컴포넌트 관리, 설정 > 디자인 토큰 관리
- 목표: 관리 화면에서 컴포넌트를 안전하게 보관하고, 토큰의 실제 결과를 확인하며, 반응형 길이 토큰을 추가·편집·검증할 수 있게 한다.

## 1. 사전 점검 결과

### 컴포넌트 관리

- 서버에는 `/api/item-component-usage`와 `/api/item-component-archive`가 구현되어 있다.
- 관리자 화면은 두 API를 호출하지 않아 컴포넌트 전체를 보관할 수 없다.
- 현재 보이는 `요소 삭제`는 컴포넌트 내부 필드만 제거하며, 컴포넌트 삭제와 의미가 다르다.
- 활성 또는 초안 섹션에서 사용 중인 컴포넌트는 서버가 409로 보관을 차단한다.

### 디자인 토큰 관리

- `현재 값` 열은 문자열만 표시하므로 색상, 그라데이션, 글꼴 크기·굵기, 간격·모서리·그림자의 결과를 빠르게 확인할 수 없다.
- 카탈로그 추가는 CSV 가져오기에만 존재하고 단일 토큰 추가 UI가 없다.
- 길이 검증은 단일 숫자와 `px|rem|em|%|vh|vw`만 허용하므로 `clamp()`, `calc()`, `min()`, `max()` 같은 반응형 표현을 저장할 수 없다.
- 고정 `px` 글꼴 크기를 발견하거나 `rem`/유동형 값으로 전환하는 안내가 없다.

## 2. 구현 범위

### A. 컴포넌트 안전 보관

1. 컴포넌트 선택 시 사용처를 조회한다.
2. 사용 중이면 섹션 수와 사용처를 표시하고 보관 버튼을 비활성화한다.
3. 미사용 컴포넌트는 확인 대화상자 후 보관한다.
4. 보관 완료 후 목록과 선택 상태를 갱신한다.
5. UI 용어는 영구 삭제가 아닌 `보관`으로 통일한다.

### B. 토큰 현재값 실물 미리보기

1. 색상·그라데이션은 스와치와 실제 값 코드를 함께 표시한다.
2. 글꼴 크기·굵기는 `Aa` 샘플에 실제 CSS 값을 적용한다.
3. 간격·모서리·그림자는 작은 도형 샘플에 실제 값을 적용한다.
4. 원본 문자열은 항상 병기해 시각 결과와 저장값을 동시에 확인한다.

### C. 반응형 길이와 글꼴 크기

1. `rem`, `em`, `%`, `vw`, `vh`, `vmin`, `vmax`, `ch`를 허용한다.
2. 안전한 `clamp()`, `calc()`, `min()`, `max()` 표현을 허용한다.
3. `font-size`가 고정 `px`이면 경고를 표시한다.
4. 고정 `px`를 기준 16px의 `rem`으로 변환하는 기능과, 모바일 최소값·뷰포트 유동값·데스크톱 최대값으로 구성된 `clamp()` 전환 기능을 제공한다.
5. 기존 px 토큰은 자동 일괄 변환하지 않는다. 시각 변화 위험을 줄이기 위해 관리자가 토큰별로 선택해 변환한다.

### D. 토큰 추가

1. 현재 토큰 세트 안에서 새 토큰 정의와 Light/Dark 값을 입력하는 폼을 제공한다.
2. 토큰 키 네임스페이스, 값 유형, CSS 속성, 단위, 중복을 즉시 검사한다.
3. 저장 시 새 정의를 카탈로그에 등록한 뒤 기존 버전 발행 흐름으로 값을 검증·활성화한다.
4. 저장 전 새 행은 취소할 수 있다.

## 3. 검증 계획

1. API 계약 테스트: 반응형 길이 허용, 위험 CSS 차단, 컴포넌트 사용 중 보관 차단 계약.
2. UI 계약 테스트: 보관·사용처 UI, 토큰 추가 폼, 실제 미리보기, rem/clamp 전환 존재 여부.
3. 빌드: 관리자 Vue 번들 빌드와 구문 검증.
4. 브라우저 확인: 컴포넌트 관리 및 디자인 토큰 관리의 데스크톱·모바일 화면, 입력·추가·전환·취소 상호작용, 콘솔 오류 확인.
5. 이상 발견 시 수정 후 같은 검증 묶음을 반복한다.

## 4. 완료 기준

- 미사용 컴포넌트만 관리자 화면에서 보관할 수 있다.
- 사용 중 컴포넌트는 보관할 수 없고 이유와 사용처가 보인다.
- 토큰 현재값 열에서 지원 유형의 실제 결과와 원본 값이 함께 보인다.
- 새 글꼴 크기 토큰을 UI에서 추가해 저장할 수 있다.
- `rem` 및 안전한 반응형 길이 함수가 서버 검증을 통과하고 위험 문자열은 계속 차단된다.
- 대상 계약 테스트, 관리자 빌드, 실제 브라우저 회귀 점검이 모두 통과한다.
