## Completed Work

### 1. Private Blob Image Proxy

Implemented a server-side proxy endpoint for private LO-FI draft images:

```text
GET /api/promo-generation-lofi-draft-image?draftId=...
```

Purpose:

- The Vercel Blob Store is private, so direct browser access to saved draft image URLs returns `Forbidden`.
- The proxy reads the stored draft image URL server-side and streams the image back to the browser.
- This keeps the Blob Store private while still allowing the prototype UI to preview generated images.

Primary file:

```text
api/promo-generation-lofi-draft-image.js
```

Verified earlier in the day with a direct request against the deployed API. The file was downloaded successfully to a temp PNG path and had non-zero length.

### 5. Worker Webhook Settings Moved To Admin Page


Implemented backend support:

```text

```

Main behavior:

- Worker webhook settings are stored per stage.
- Supported stages include:
  - `integrated_brief`
  - `lofi_draft`
  - `final_design`
  - `promo_ui_design`
- Admin/DB settings take priority over environment variables and request-provided URLs.
- Environment variables remain as fallback.
- Request-provided webhook URLs are retained only for local/dev or legacy fallback behavior.
- Production host validation uses allowlist checks to reduce SSRF risk.

Migration added:
