## 2. 반영 내용

### 2.1 CTA URL 안전성

`visual-editor/src/editor-utils.mjs`의 `normalizeCtaUrl()`에서 다음 링크만 허용한다.

- `http:` 및 `https:` URL
- `/`로 시작하는 동일 Origin 경로
- `./`, `../` 상대 경로
- `#` 페이지 내부 앵커

`javascript:`, `data:`, 프로토콜 상대 URL과 해석이 불명확한 값은 `#`으로 변환한다. Renderer는 CTA 링크 출력 전에 이 함수를 사용한다.

### 2.2 Snapshot 저장 오류 처리

- Snapshot 직렬화와 `localStorage.setItem()`을 `persistSnapshot()`으로 분리했다.
- 저장 공간 초과와 일반 저장 실패 메시지를 구분한다.
- 저장 성공 후에만 Web Output 창을 연다.
- 오류는 Visual Editor 화면의 `role="alert"` 메시지로 표시한다.
- 이미지 교체 또는 제거 시 이전 저장 오류를 정리한다.

현재 저장 방식은 PoC 범위의 Data URL과 `localStorage`를 유지한다.

### 2.3 자유 배치 좌표 정합성

- X 좌표는 `xPct`, Y 좌표는 `yPx`를 사용한다.
- CONTENT 패널 표시는 `X n% · Y npx`로 통일했다.
- 자동 배치 복원 시 `positionMode`, `xPct`, `yPx`, 레거시 `yPct`를 제거한다.

### 2.4 내비게이션 및 preview 서버

- Promo Builder 링크를 `/prototype/index.html`로 수정했다.
- 로컬 preview 서버가 `/prototype/*` 경로를 실제 정적 파일에 매핑한다.
- `/favicon.ico`는 204로 응답해 불필요한 404를 제거한다.

### 2.5 추가 런타임 수정

저장 오류 알림을 추가하는 과정에서 Vue 조건부 렌더링 체인이 잘못 연결되어 템플릿 로드 전에 workspace가 렌더링되던 문제를 발견했다. workspace 조건을 `v-if="!loading && !error"`로 명시해 초기 런타임 오류를 제거했다.

## 7. 알려진 제한사항

- 배경 이미지는 Data URL로 Snapshot에 포함되므로 브라우저 저장 한도 영향을 받는다.
- Web Output은 현재 브라우저의 `localStorage` Snapshot 기반이다.
- X는 비율, Y는 픽셀 단위를 사용하는 혼합 좌표 계약이다.
- 모바일 전용 좌표 override는 없다.
- 아이템 크기와 z-index를 UI에서 직접 편집할 수 없다.
- 최신 Vercel 배포 상태는 이 handoff 작성 시점에 검증하지 않았다.
