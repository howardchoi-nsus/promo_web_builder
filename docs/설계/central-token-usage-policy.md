# 중앙 디자인 토큰 사용 정책

## 관리 위치와 단일 기준

관리자 → 디자인 토큰 → **토큰 사용 정책**에서 대상·속성·상태별 토큰을 연결하고 Draft 저장/검증 후 활성화합니다.

`shared/token-usage-policy.mjs`가 정책 항목, 용도/상태 적합성, 등록 토큰 후보, 런타임 연결 변수의 단일 기준입니다. 토큰 값·참조 관계는 기존 토큰 라이브러리에서 관리합니다. 정책은 별도 컬럼을 토큰 CSV에 추가하지 않습니다.

일반 텍스트에는 버튼·카드 등 다른 컴포넌트 전용 토큰을 연결할 수 없습니다. 미연결 필수 항목은 생성 차단, 선택 항목은 생략합니다. 누락을 임의 값이나 다른 용도의 토큰으로 보충하지 않습니다.

## 버전과 적용

마이그레이션 `085_token_usage_policy.sql`이 필요합니다. 활성 토큰 라이브러리가 준비된 뒤 관리자에서 정책을 저장합니다. 정책 버전은 변경마다 새 레코드로 기록되며 활성 버전은 하나입니다. 오래된 화면의 저장은 거부합니다.

초기 제안은 등록·유효성이 확인된 토큰만 연결합니다. 현재 저장소의 Dark 라이브러리에는 일반 텍스트 전용 기본 색상 토큰이 없으므로 **text.primary는 미연결**입니다. 본문용 토큰을 승인·등록하고 이 항목에 연결해야 활성화할 수 있습니다. 테스트에서 사용한 `--text-primary`는 테스트 데이터이며 실제 라이브러리에 추가하지 않았습니다.

새 구성은 활성 정책을 검증한 뒤 토큰 버전·값·정책 ID/버전을 결과 문서에 고정합니다. 라이브러리 값 변경 시 새 구성에서 정책을 다시 검증합니다. 기존 문서에 고정된 토큰·정책은 자동으로 최신 값으로 바꾸지 않습니다. 정책 이전 문서는 기존 호환 경로를 유지하며, 정책 도입 후 새 생성이 필요합니다.

## 연결 경로

- 관리자 API: `/api/design-token-usage-policy` (관리자 인증, 같은 사이트 저장, 이력 조회)
- 컴포넌트 편집/활성화/RenderSpec 검증: 활성 라이브러리와 정책 카탈로그 사용
- 신규 구성·섹션 계획: 정책에 허용된 토큰과 용도 정보를 제공하고 결과에서 다시 검증
- 컴파일/문서 수정 저장: 대상·속성·상태가 다르면 거부 또는 선택 스타일 생략 진단
- 미리보기/HTML 출력: 문서에 고정된 정책에서 파생한 `--render-policy-*` 연결 변수를 사용
- 디자인 미리보기의 **디자인 토큰 적용 내역**: 해당 문서의 정책 버전·용도·등록 토큰·값·연결 상태 표시 (연결된 상태도 실제 요소/상태가 있을 때 사용)
- 라이브러리 수정: 활성 정책의 필수 토큰 삭제/호환되지 않는 변경 차단

`--render-policy-*`는 등록 토큰을 `var(--등록토큰)`으로 참조하는 출력 전용 변수입니다. 해당 이름은 정책의 소스 토큰으로 선택할 수 없습니다. 기존 토큰 이름과 연결 변수의 충돌을 방지합니다.

## CSS와 이전 호환 동작

정책이 고정된 문서는 `has-token-usage-policy` 클래스를 사용합니다. 이 경로에서는 기존 15px 반경, 임의 그림자, 14px 간격, 버튼 800 굵기, 모바일 clamp/1.08 줄 높이 등 시각 대체값을 사용하지 않습니다. 미연결 속성은 생략하거나 CSS의 중립/상속 상태로 둡니다. 좌표·열 수·너비 같은 구조적 레이아웃은 별도로 유지합니다.

정책 이전 문서에 대한 기존 CSS 및 매핑은 호환 경로로만 남아 있습니다. 새 단일 라이브러리 구성은 활성 중앙 정책이 없으면 명시적으로 중단합니다. 따라서 신규 경로가 이전 버튼→본문 대체 매핑으로 내려가지 않습니다.

## 검증

- `scripts/test-token-usage-policy.mjs`: 필수 누락, 다른 컴포넌트/상태 거부, 런타임 연결, RenderSpec, 정책 고정 컴파일
- `scripts/test-token-usage-policy-api.mjs`: 인증/Origin, Draft/활성화, 미연결·오래된 라이브러리 차단
- `scripts/test-token-usage-policy-browser.mjs`: 관리자 옵션 필터링, 필수 미연결 활성화 금지, 저장·활성화·이력 갱신
- `scripts/test-component-render-spec-renderer-browser.mjs`: Desktop/Mobile와 정책 경로의 고정 대체값 배제
- migration 085는 로컬 PostgreSQL 호환 환경에서 중복 DDL, 이력, 활성 1개, 충돌·라이브러리 변경 롤백을 검증했습니다.

운영 DB에 migration/정책 활성화를 적용하지 않았으며 Production 배포도 별도입니다.
