# Directus MCP와 프로모션 웹빌더 활용 방법

## 한 줄 설명

**운영자가 자연어로 프로모션을 요청하면, AI가 Directus MCP를 통해 내용을 정리·저장하고, 프로모션 웹빌더가 그 데이터를 이용해 웹페이지를 만든다.**

## 전체 흐름

```text
운영자의 자연어 요청
예: “한국 여름 이벤트 페이지를 만들어줘.”
                ↓
AI + Directus MCP
  └─ 제목·기간·지역·이미지·약관 등을 정리해 Directus에 저장
                ↓
프로모션 웹빌더
  └─ 템플릿·섹션·디자인 설정을 불러와 페이지 생성
                ↓
미리보기와 사용자 수정
                ↓
검토·승인 후 최종 웹페이지 출력
```

Directus MCP는 콘텐츠와 설정을 준비하는 역할을 하고, 실제 화면 생성·편집·출력은 프로모션 웹빌더가 담당한다.

## 역할 구분

| 구분 | 하는 일 |
|---|---|
| Directus | 콘텐츠, 템플릿, 이미지, 다국어, 승인 상태 저장 |
| Directus MCP | 자연어 요청을 이해해 Directus 데이터를 검색·작성·수정 |
| 프로모션 웹빌더 | 데이터를 이용해 실제 페이지 생성·미리보기·편집 |
| 사람 | 결과 확인, 수정, 승인, 공개 결정 |

## 활용 예시 1 — 프로모션 초안 만들기

운영자가 다음과 같이 요청한다.

> “8월 한국 사용자 대상 여름 프로모션을 만들어줘. 메인 문구는 SUMMER BONUS이고 종료일은 8월 31일이야.”

AI가 MCP를 통해 다음 내용을 Directus에 저장한다.

- 프로모션 이름과 기간
- 대상 국가와 언어
- 메인 문구와 설명
- 필요한 섹션
- 버튼 문구
- 약관 초안

웹빌더는 저장된 내용을 불러와 템플릿과 미리보기 페이지를 구성한다.

## 활용 예시 2 — 기존 템플릿 활용하기

> “지난 여름 프로모션과 비슷하게 만들되 색상은 파란색 계열로 바꿔줘.”

AI는 Directus에서 기존 여름 프로모션과 사용된 템플릿을 찾는다. 기존 콘텐츠를 새 Draft로 복사하고 변경된 조건을 저장한다. 웹빌더는 복사된 Draft를 이용해 새로운 페이지를 만든다.

## 활용 예시 3 — 여러 국가 버전 만들기

> “승인된 한국어 프로모션을 영어와 일본어 버전으로 만들어줘.”

AI는 MCP를 이용해 번역 초안을 Directus에 저장한다. 국가별 기간·약관·버튼 링크를 확인하고, 웹빌더는 같은 디자인으로 언어별 페이지를 생성한다.

## 활용 예시 4 — 이미지와 누락 내용 찾기

> “모바일 이미지가 없거나 약관이 비어 있는 프로모션을 찾아줘.”

AI는 Directus 데이터를 검색해 누락 항목을 보여준다. 운영자가 이미지를 추가하거나 약관을 작성하면 웹빌더에서 다시 미리보기를 생성할 수 있다.

## 활용 예시 5 — 검토와 승인

> “현재 Draft와 이전 공개 버전의 차이를 알려줘.”

AI는 제목, 기간, 이미지, 약관 등의 차이를 요약한다. 운영자가 Directus에서 승인하면 웹빌더가 승인된 버전을 기준으로 최종 결과를 출력한다.

## 연결을 위해 필요한 기능

Directus MCP만 설치하면 자동으로 웹빌더와 연결되는 것은 아니다. 다음 연결 기능이 필요하다.

1. Directus에 프로모션·템플릿·이미지 Collection 구성
2. Directus 데이터를 현재 웹빌더 형식으로 변환하는 Adapter
3. Directus의 생성 요청을 웹빌더에 전달하는 API 또는 Flow
4. 웹빌더의 진행 상태와 결과를 Directus에 돌려주는 Callback
5. Draft·검토·승인·공개 권한 설정
6. 실행 당시 설정을 고정하는 Snapshot

## 권장 사용 범위

### MCP에 맡길 작업

- 콘텐츠와 설정 검색
- 프로모션 Draft 작성
- 기존 프로모션 복사
- 번역 초안 생성
- 누락 항목 확인
- 변경 내용 비교와 요약

### 웹빌더에 맡길 작업

- 템플릿과 레이아웃 구성
- AI 이미지와 디자인 생성
- 미리보기와 직접 편집
- Desktop·Mobile 품질검사
- 최종 웹페이지 출력

### 사람이 결정할 작업

- 최종 콘텐츠 승인
- 모델·Prompt 활성화
- 공개와 삭제
- 중요한 약관과 규정 확인

## Directus MCP 기능과 활용 범위 비교

| Directus MCP 수행 가능 기능 | 우리 서비스에서 활용 가능한 기능 | 적용 판단 |
|---|---|---|
| 현재 사용자와 권한 확인 | 요청한 운영자의 조회·수정 가능 범위 확인 | 활용 |
| Collection 구조 조회 | 프로모션·템플릿·섹션 데이터 구조 확인 | 활용 |
| Field 구조 조회 | 필수 입력값, 타입, 관계 확인 | 활용 |
| Item 검색·조회 | 기존 프로모션, 템플릿, 번역, 설정 검색 | 적극 활용 |
| Item 생성 | 새로운 프로모션과 번역 Draft 등록 | 적극 활용 |
| Item 수정 | 제목·본문·기간·태그·번역 초안 수정 | 활용 |
| Item 삭제 | 프로모션과 설정 데이터 영구 삭제 | 사용 제한 |
| File 조회 | 기존 PC·모바일 이미지와 문서 검색 | 활용 |
| URL File Import | 승인된 외부 이미지를 Directus로 가져오기 | 제한적으로 활용 |
| File 정보 수정 | 이미지 설명, 태그, 저작권 정보 입력 | 활용 |
| Flow 목록 조회 | 사용 가능한 검토·생성 요청 Flow 확인 | 활용 |
| Flow 실행 | 검토 요청, 번역 요청, 웹빌더 생성 요청 시작 | 허용된 Flow만 활용 |
| Comment 조회·작성 | 검토 의견 확인과 수정 요청 기록 | 활용 |
| Markdown·HTML 변환 | 약관과 본문 형식을 Directus 필드에 맞게 변환 | 활용 |
| 저장된 Prompt 조회·사용 | 프로모션 초안·번역·검토 요청 형식 표준화 | 선택 활용 |
| Field 생성·수정 | Directus 데이터 구조 변경 | 운영에서는 사용 제한 |

### 적극 활용할 기능

- 기존 프로모션과 템플릿 검색
- 프로모션 Draft 생성
- 제목·본문·기간·지역 정보 수정
- 번역 초안 생성과 저장
- 누락된 필수값 확인
- 이미지 검색과 메타데이터 관리
- 변경 전후 비교와 요약
- 검토 의견 작성
- 승인된 생성 요청 Flow 실행

### 기술적으로 가능하지만 제한할 기능

- 데이터 영구 삭제
- Collection·Field 구조 변경
- 활성 Prompt와 Model 직접 변경
- 콘텐츠 자동 승인과 공개
- 제한 없는 Flow 실행
- 출처가 확인되지 않은 외부 파일 Import

이 기능들은 MCP 전용 계정에서 권한을 제거하거나 사람의 추가 승인을 받도록 구성한다.

## Directus MCP만으로 수행할 수 없는 기능

| 수행할 수 없는 기능 | 별도 담당 |
|---|---|
| 디자인된 웹페이지 화면 생성 | 프로모션 웹빌더·Renderer |
| 새로운 페이지 Layout 결정 | Composition Agent·Layout Engine |
| GPT·Gemini 모델 실행 | Agent Runner 또는 AI 실행 서비스 |
| 이미지 생성 결과 품질검사 | Visual QA 기능 |
| 작업 Queue·재시도·중복 방지 | 서비스 작업 관리 기능 |
| 웹페이지 배포와 호스팅 | 배포 서비스 |
| API Key·Token 보관 | Secret Manager |

Directus에 Custom Flow나 Extension을 추가하면 MCP가 해당 작업을 시작하도록 만들 수는 있다. 하지만 실제 생성·검사·배포는 연결된 외부 서비스가 수행한다.

## 최종 정리

```text
Directus MCP = 자연어 기반 관리 도우미
Directus     = 콘텐츠와 설정 저장소
웹빌더       = 실제 페이지 제작 도구
사람         = 검토·승인·공개 담당
```

따라서 Directus MCP를 사용하면 프로모션 웹빌더를 없애는 것이 아니라, **웹빌더에 넣을 콘텐츠와 설정을 더 빠르고 쉽게 준비하고 관리할 수 있다.**
