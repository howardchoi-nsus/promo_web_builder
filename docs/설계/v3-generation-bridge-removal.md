# V3 생성 브리지 제거

V3 생성 요청이 기존 integrated brief → 이미지 생성 워커로 전달되던 연결을 제거했습니다.

- `_promo-generation-v3-adapter.js` 삭제.
- `POST /api/internal/v3/generation-jobs`와 V3 재생성은 인증 후 HTTP 410 (`V3_GENERATION_RETIRED`)을 반환합니다. 피드백 저장, 작업 생성, 워커 호출은 수행하지 않습니다.
- 기존 작업 GET 조회는 유지하며 V3 작업 테이블만 조회합니다. 이전 생성 실행 테이블의 상태로 결과를 재해석하지 않습니다.
- 현재 AI 빌더의 직접 모델 호출, 구성 제안·편집·이미지 생성·검증·출력 경로는 유지합니다.
- V1/V2 워커, 워크플로 파일, 공용 관리자 프롬프트와 모델 설정은 V3 전용이 아니므로 유지합니다.

DB 이력과 환경 변수는 삭제하지 않습니다. 외부에서 이미 실행 중인 워커는 이 코드 변경으로 중단되지 않습니다. 배포 전에는 현재 서비스에 반영되지 않습니다.
